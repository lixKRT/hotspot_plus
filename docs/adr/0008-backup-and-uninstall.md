# 保留用户资产，确认后才恢复

状态：已接受

升级保留配置和静态租约，同时丢弃租约库、进程标识、锁、socket、临时文件和日志。卸载会在删除模块数据前，先创建位于模块数据目录之外的版本化备份。之后重新安装时必须能检测到该备份并提示恢复，而不是静默套用。

## 影响

备份和恢复必须带版本并经过校验；未知或无效设置绝不能覆盖可用配置。全新安装的恢复提示需要用户明确决定，并在启动器 App 未安装时仍有可用路径。运行状态和日志不是备份输入。

备份默认存放在 `/data/adb/hotspot_plus_backups/`，仅 root 可读。备份包包含配置、静态租约、来源信息（创建时间、模块版本、Android 构建）和校验和；运行租约、进程状态和日志不包含在内。配置会完整备份，包括存在时的 `FALLBACK_SSID` 和 `FALLBACK_PASS`，因为备份属于设备机主；机主有责任保护它。安装器只检测并校验备份，不提示输入；首次打开 App/WebUI 时显示恢复提示；命令行提供显式 list/restore 命令用于无界面恢复。导出到 `/sdcard/Download` 是显式用户操作，不是自动恢复来源。

恢复提示只在此前没有用户配置可保护时出现。安装器创建的默认配置会被标记，因此不会抑制提示；已有用户配置时不自动提示，但备份仍可用于显式恢复。

卸载会在删除模块数据前尝试创建备份，并有有限重试。重试耗尽后，记录醒目错误和备份日志路径，然后继续删除，因为发起卸载是设备机主的显式破坏性选择，而 Magisk 没有可靠的交互式提示。这取代了此前“备份失败必须阻断卸载”的解释：不另设“不备份继续”的交互提示。机主也可以先运行 `hsp backup`，修好备份缺陷后再移除模块。
