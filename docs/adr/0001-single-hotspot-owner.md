# 单一热点所有者

状态：已接受

热点增强与现有的 `oneplus8t_fixed_hotspot` 模块都会影响热点启动、网关和客户端地址分配。热点增强将成为热点生命周期、固定网关、DHCP 行为、界面和卸载回滚的唯一所有者。旧模块仅作为验证期间的临时回滚路径保留，不是运行时依赖；热点增强通过设备验收后，旧模块退役。热点增强不继承旧模块的 APEX 子网补丁。

## 考虑过的方案

- 让旧模块继续负责开机启动：否决。这样会有两个热点所有者，并把启动耦合到一个 APEX 补丁上。
- 把旧模块整体并入热点增强：否决。它的 APEX 补丁是另一套风险更高的机制，热点增强不需要保留它。

## 影响

热点增强必须自行证明开机启动路径可用。迁移期间，两个模块不得同时管理热点启动或客户端地址。

如果探测证明 root/Tethering 路径无法可靠地在开机时启动热点，回退方案是把一个最小化的开机助手并入热点增强，而不是继续依赖旧模块。该助手需要独立的包身份、最小特权权限，并随热点增强一起卸载；是否采用取决于探测证据。
