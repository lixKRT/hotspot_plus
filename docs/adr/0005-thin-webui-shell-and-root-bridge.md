# 薄 WebUI 外壳与长期 root 桥

状态：已接受

热点增强只保留一套本地 WebUI 作为用户界面，App 只作为薄壳。命令行仍是权威操作接口，因此同一套行为可以在没有界面时测试。App 保留长期 root 桥，并向本地页面暴露兼容 `window.ksu.exec` 的命令执行能力，与上游设计一致。

这接受了一项重要的安全取舍：本地 WebUI 中的任意脚本执行等价于设备 root 权限。模块及其 WebUI 被当作可信代码。App 不得加载不可信远程内容，不得把 root 桥暴露给无关来源，也不得允许其他应用向桥注入命令。

导出型切换 Activity 不得被任意应用调用。快捷方式入口是一个显式组件，由 App 签名级权限保护。如果目标构建上的启动器无法调用该入口，则移除外部快捷方式，而不是放宽权限。

## 影响

WebUI 及其加载的所有资源都属于可信计算基础。未来若加载远程内容或接受不可信 HTML，必须重新评估此决定。App 仍需对导出接口和导航做明确限制。源码仓库不得包含签名密钥、构建产物、设备序列号、观测到的客户端 MAC 地址或热点凭据。
