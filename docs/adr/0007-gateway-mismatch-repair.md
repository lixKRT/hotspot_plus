# 网关不符时有限修复，失败后降级

状态：已接受

热点增强优先使用配置的 `192.168.42.1/24` 网关。如果是系统先启动热点并落在其他子网，热点增强可重启热点一次以套用配置网关。如果重启后仍不符合，热点保持可用并进入降级模式，静态租约按实际子网映射，而不是反复重启。

如果是模块自己启动热点但固定网关请求未生效，不是立即降级，而是重试：首次启动后最多再重启两次，间隔约 5 秒和 15 秒。全部尝试仍失败时，本次会话降级。

两条修复路径不叠加。系统启动的热点只获得一次修复重启；如果该次重启仍未得到配置网关，就降级，不再享有模块启动路径的额外重试额度。修复额度按热点会话计数；用户主动关闭再开启会创建新会话，并获得新的有界尝试额度。

## 影响

重启会断开当前客户端，必须有界，不能形成重启循环。界面和日志必须显示修复尝试及其结果。
