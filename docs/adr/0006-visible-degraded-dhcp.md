# DHCP 故障可见，热点保持可用

状态：已接受

如果模块 DHCP 无法启动、iptables 所有权规则无法安装，或 `udhcpd` 连续退出，热点增强必须撤销任何不完整的接管，并把 DHCP 交还系统 DHCP。热点仍保持可用，但界面和状态输出必须显示降级模式、原因和重试入口。

## 考虑过的方案

- 静默回退到系统 DHCP：否决。用户会看到网络正常，却在不知情的情况下失去静态租约。
- 阻断或关闭热点：否决。DHCP 缺陷不应让热点完全不可用。

## 影响

清理路径必须足够原子化，避免同时运行两个 DHCP 响应者，或把所有 DHCP 应答都丢弃。状态必须区分正常工作、降级工作和已关闭热点。
