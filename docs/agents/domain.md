# Domain Docs

Before exploring, read:

- `GLOSSARY.md` at the repository root.
- `docs/adr/` for decisions touching the area being changed.

Use the glossary's vocabulary in issue titles, specs, tests, and code comments. If an output contradicts an ADR, surface the conflict explicitly instead of silently overriding it.

This is a single-context repository: one glossary and one ADR directory.
